# Product Vision: FinFocus

## Что такое FinFocus

FinFocus — веб-приложение для планирования личного и семейного бюджета. В отличие от классических трекеров расходов, которые отвечают на вопрос "куда ушли деньги", FinFocus отвечает на вопрос **"хватит ли денег 15-го числа"**.

Ядро продукта — **кассовый календарь**: пользователь видит точный прогноз остатка на каждый день с учётом запланированных поступлений и списаний. Поверх календаря работает система **целевых накоплений** с автоматическим распределением бюджета между несколькими целями по приоритетам.

FinFocus не требует педантичного учёта каждой покупки. Механизм сверки позволяет в любой момент синхронизировать модель с реальным балансом, заполняя пробелы одной корректировкой.

---

## Для кого

**Семьи с крупными целями.** Планируют покупку квартиры, автомобиля или отпуска и хотят понимать, сколько откладывать каждый месяц, чтобы успеть к сроку. Несколько целей одновременно — норма.

**Люди с нерегулярными доходами.** Фрилансеры, предприниматели, сотрудники с бонусной частью зарплаты. Им критично видеть остатки на конкретные даты, а не средние значения за месяц.

**Пользователи, совмещающие текущие расходы с накоплениями.** Хотят автоматически распределять свободные средства между целями, не занимаясь ручными расчётами каждый месяц.

**Те, кто устал от "категорийного" учёта.** Не хотят записывать каждый кофе — хотят видеть кассовый план и быстро сверять баланс с реальностью.

## Ядро продукта (Must Have)

### Кассовый календарь
Сетка дней с прогнозом остатка на каждый день. Цветовая индикация (зелёный / жёлтый / красный) мгновенно показывает, когда деньги заканчиваются. Навигация вперёд на 12 месяцев.

### Повторяющиеся операции
Зарплата, аренда, подписки — вводятся один раз и автоматически генерируют прогноз. Anchored-алгоритм корректно обрабатывает разную длину месяцев (31 января -> 28 февраля -> 31 марта).

### Накопительные цели с автораспределением
Несколько целей с приоритетами. Жадный алгоритм распределяет бюджет: цель с высшим приоритетом финансируется первой, остаток — на следующие. Три режима накоплений (свободный / средний / строгий) регулируют агрессивность.

### Базовый дашборд
Четыре ключевые метрики (баланс, доходы, расходы, накопления) и график cashflow за период. Переключатель месяц/год.

### Категоризация операций
16 предустановленных категорий. Категория опциональна — пользователь не обязан классифицировать каждую операцию. Quick-add chips для частых категорий ускоряют ввод.

### Сверка баланса
Ввёл фактический баланс — система создала корректирующую запись. Компенсирует пропущенные операции без необходимости восстанавливать каждую.

## Что НЕ делаем

| Область | Почему нет |
|---|---|
| AI-рекомендации и "умные" советы | Усложняют MVP, требуют данных для обучения |
| Интеграции с банками | Юридические и технические барьеры, зависимость от API банков |
| Нативные мобильные приложения | Адаптивный веб покрывает мобильный сценарий на старте |
| Мультивалютность | Усложняет модель данных, нишевая потребность для MVP |
| Инвестиционный трекер | Другой продукт с другой аудиторией |
| Социальные функции | Сравнение с друзьями, рейтинги — не решают задачу планирования |
| Бухгалтерия и налоги | Другая предметная область |

## Ключевые метрики успеха

### Продуктовые
- Время до первой добавленной цели < 10 минут
- Retention rate 30 дней > 25%
- Активность: > 3 сессии в неделю в первый месяц

### Технические
- Время загрузки календаря < 2 сек
- Uptime > 99%
- 0 критических багов в production

### Бизнес
- Готовность платить > 60% после trial
- Вирусность: > 15% пользователей приглашают других

## Конкурентное позиционирование

```
             Учёт прошлого ← → Планирование будущего
                    │
  Дзен-мани ●       │
  CoinKeeper ●      │        ● FinFocus
  1С:Деньги ●       │
                    │
         Категории ← → Кассовый календарь
```

FinFocus занимает нишу **кассового планирования с целевым бюджетированием** — пересечение, которое не покрывают классические трекеры расходов.

# FinFocus — Инструкция для бета-тестеров

## Что это?

FinFocus — персональный финансовый планировщик. Приложение работает в вашем браузере
и помогает отслеживать доходы, расходы и цели накопления.

## Установка за 3 шага

### Шаг 1: Установите Python (если ещё не установлен)

Скачайте Python с https://www.python.org/downloads/ (версия 3.10 или новее).

- **Windows**: при установке **обязательно** отметьте галочку **"Add Python to PATH"**
- **macOS**: скачайте установщик с python.org или выполните `brew install python3`
- **Linux (Ubuntu/Debian)**: выполните в терминале:
  ```
  sudo apt install python3 python3-venv
  ```

### Шаг 2: Распакуйте архив

Распакуйте скачанный ZIP-файл в любую удобную папку.

### Шаг 3: Запустите

- **Windows**: дважды кликните по файлу `start.bat`
- **Linux/macOS**: откройте терминал в папке с приложением и выполните:
  ```
  ./start.sh
  ```

Приложение откроется в браузере автоматически. При первом запуске потребуется
1-2 минуты на установку зависимостей (нужен интернет). Повторные запуски будут быстрыми.

## Частые вопросы (FAQ)

**Приложение не запускается, пишет "Python не найден"**

Установите Python (шаг 1 выше). На Windows убедитесь, что при установке
отметили "Add Python to PATH". После установки Python перезапустите скрипт.

---

**Пишет "Порт 8050 занят"**

Другое приложение уже использует этот порт. Запустите FinFocus на другом порту:

- Windows: `set PORT=8051 && start.bat`
- Linux/macOS: `PORT=8051 ./start.sh`

---

**Браузер не открылся автоматически**

Откройте браузер вручную и перейдите по адресу: http://localhost:8050

---

**Как остановить приложение?**

Нажмите `Ctrl+C` в окне терминала. На Windows можно просто закрыть окно.

---

**Как обновить до новой версии?**

1. Скачайте новый ZIP-архив
2. Распакуйте в ту же папку (с заменой файлов)
3. Запустите `start.bat` или `./start.sh` — зависимости обновятся автоматически

---

**Данные сохраняются при обновлении?**

Да. Ваши данные хранятся в файле `data/finfocus.db`, который не перезаписывается при обновлении.

# Brief — эскиз полоски-меню (FinFocus, Epic-11 кусок 3)

## Артефакт

Эскиз-спецификация UI-компонента: узкая вертикальная **полоска-меню
(icon rail)**, заменяющая нынешний широкий сайдбар FinFocus на всех
не-дашборд экранах. Формат вывода — одностраничный HTML (`vN.html`),
рендерится `page_shot.sh` как ОДНА страница (не дека).

Это НЕ маркетинговый визуал и НЕ дека. Это рабочий эскиз, который
разработчик переносит в CSS один в один. Приоритет — точность и
переносимость, а не «вау».

## Аудитория

Владелец продукта (принимает вид логотипа и геометрию полоски) и
разработчик (переносит эскиз в код). Решение, которое принимают по
эскизу: **какой знак-логотип ставим вверху полоски** и утверждение
пропорций.

## Закреплённое направление (НЕ менять)

- **Тема/светлота:** СВЕТЛАЯ. Приоритет над дефолтом бренд-скилла.
- **Тон:** сдержанный, инженерный. Подписи-ярлыки, без рекламных
  формулировок и восклицаний.
- **Плотность:** умеренная. Крупно показана сама полоска и её
  состояния; вокруг — воздух.
- **Визуальный язык:** glassmorphism-lite, как в реальном приложении:
  полупрозрачное белое стекло, размытие фона, мягкая тень, скругления
  14px. БЕЗ градиентных заливок текста, БЕЗ неона, БЕЗ 3D.
- **Анимация:** статичный эскиз. Разворот полоски показывается
  РАСКАДРОВКОЙ (3 кадра в ряд), а не CSS-анимацией — эскиз должен
  быть читаем на неподвижном скриншоте.

## Фирстиль (выжимка для графиста)

⚠️ Берём палитру **FinFocus**, НЕ корпоративный Leadgid (решение
владельца 2026-08-27): эскиз переносится в код один в один, чужая
палитра означала бы перекрашивание при переносе.

Точные значения — из `app/assets/custom.css` и `panel.css` проекта:
- Базовый акцент: `#2ecc71` (зелёный), тёмный вариант `#27ae60`
- Второй акцент (точечно): `#3498db` (синий, слой «резерв»)
- Светлота фона: СВЕТЛЫЙ. Фон страницы — градиент
  `linear-gradient(135deg, #eaf2ee 0%, #dce8e0 100%)`
- Текст: основной `#2c3e50`, вторичный `#64748b`, приглушённый `#94a3b8`
- Карточка-стекло: `rgba(255,255,255,0.25)`, `backdrop-filter: blur(16px)`,
  граница `1px solid rgba(255,255,255,0.5)`, тень
  `0 8px 32px 0 rgba(31,38,135,0.07)`
- Скругления: 14px (крупные блоки), 10px (мелкие), 9999px (активная пилюля)
- Иконки: Bootstrap Icons (в проекте уже подключены)

## Содержание

Режим — эскиз с нуля, но состав ЗАДАН спекой
`.obsidian-docs/design/epic-11-panel-batch-3/spec.md` (FR-1..FR-5).
Ничего не выдумывать сверх этого списка.

**Состав полоски (сверху вниз), ширина ~60px:**
1. Логотип-«щиток» — ведёт на дашборд, визуально выделен
2. Иконки 4 разделов (дашборд — это логотип, отдельным пунктом НЕ дублируется):
   - Календарь — `bi-calendar3`
   - Операции — `bi-list-ul`
   - Аналитика — `bi-bar-chart`
   - Цели — `bi-target`
3. Внизу — аватар пользователя (эмодзи в круге, зелёный подклад
   `rgba(46,204,113,0.15)`), открывает окно профиля

**Чего в полоске НЕТ** (осознанные решения владельца, не забыть):
- НЕТ пункта «Настройки» (страницы не существует, вела на 404)
- НЕТ номера версии (переехал в окно профиля)

### Логотип — РЕШЕНО (владелец, 2026-08-27)

Знак — **домик `bi-house-door`**, семантика «Домой». Предварительный:
заменяется без правки раскладки, когда появится настоящий логотип.

История решения: сравнение четырёх вариантов знака (спидометр,
рубильники, монограмма «F», авторский «щиток с автоматами») собрано
в v3.html и отвергнуто целиком. Причина — **«щиток» был метафорой для
объяснения концепции дашборда, а не заданием на форму знака**; поиск
буквального изображения электрощитка был ошибкой постановки задачи.
Блок сравнения удалён из v4, знак заменён во всех четырёх местах
(полоска + три кадра раскадровки).

## Что показать (охват — решение владельца: «полоска + состояния»)

Одностраничный эскиз из четырёх блоков:
1. **Полоска целиком** — крупно, в натуральную высоту экрана,
   с активным разделом «Календарь»
2. **Состояния пункта** — три штуки рядом, крупно: обычный /
   при наведении (с раскрытой подписью-tooltip справа от иконки) /
   активный (зелёная пилюля)
3. **Разворот при входе в раздел** — раскадровка из 3 кадров:
   только логотип → полоска раскрыта наполовину → полностью.
   Подпись: «проигрывается при входе с дашборда, при переходах
   между разделами не повторяется»
4. ~~Сравнение вариантов логотипа~~ — удалён в v4: решение принято

Блок «в контексте экрана» владелец НЕ заказывал — не добавлять.

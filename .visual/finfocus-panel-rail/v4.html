Состояния пункта

Раздел «Аналитика» во всех трёх

Обычное

Знак --color-text-secondary #64748b, фона нет. Полоска не перетягивает внимание с содержимого страницы.

Аналитика

При наведении — язычок

Подкладка rgba(46,204,113,.10); справа выезжает подпись: фон #2c3e50, текст белый 12.5px/600, radius 10px, отступ 9px, треугольный носик. Слой поверх содержимого (AC-3).

Активное

Пилюля #2ecc71, radius 9999px, знак белый, тень 0 2px 8px rgba(46,204,113,.20). Вычисляется на построении из адреса — обработчика нет (C-1).

Разворот при входе в раздел

Раскадровка · CSS-переход высоты сверху вниз
0 мсТолько логотип

Кожух схлопнут до высоты знака. Стартовое состояние перехода.

~110 мсПоловина

Кожух растёт вниз, пункты открываются по мере появления места. Собственной анимации у пунктов нет.

🦊
~220 мсПолностью

Конечное состояние: аватар прижат к низу распоркой. Дальше полоска не двигается.

Когда проигрывается. Только при входе с дашборда, где полоски нет вовсе. Разворот показывает появление навигации, а не смену раздела.

Когда не повторяется. Переходы между разделами: полоска уже на экране, меняется только подсветка активного пункта.

Уменьшенное движение. При системной настройке prefers-reduced-motion перехода нет — полоска сразу в конечном состоянии (NFR-2, AC-6).

Что решается по этому листу: утверждение геометрии — ширина 60 px, слот 44 px, знак 22 px (блок 1). Знак логотипа — домик «Домой» (bi-house-door), выбран как предварительный: заменяется без правки раскладки.  ·  Вне листа: мобильная адаптация (Epic-08), анимация перехода дашборд↔раздел (Epic-10), страница /settings — по Out of scope спеки.  ·  Реализация: компонент без серверных обработчиков (C-1), схлопывание колонки одним правилом :empty (C-2), вход в профиль только через Store-триггер (C-3).

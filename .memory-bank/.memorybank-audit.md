## Специфика проекта

### Критичные детали отражены ✅

**Starting Balance Formula**:
```
остаток на дату = starting_balance + SUM(доходы) - SUM(расходы) до даты
```
📍 Указано в: `index.md`, `modules/database.md`

**Monthly Contribution Formula**:
```python
monthly_contribution = (target_amount - current_amount) / months_remaining
```
📍 Указано в: `index.md`, `modules/database.md`

**Pattern-Matching Callbacks Issue** (КРИТИЧНО):
- Проблема: автовызовы при DOM updates
- Решение: проверка `ctx.triggered[0].get('value') is None`
- Статус: Исправлено в Батче 4
📍 Указано в: `architecture.md`, `modules/ui-components.md`, `code-style.md`

**Session Management Pattern**:
- Сервисы используют `flush()`, caller делает `commit()`
- Атомарность операций через try/except/rollback
📍 Указано в: `architecture.md`, `modules/services.md`, `code-style.md`

# EPIC-11 «Щиток», кусок 3: полоска-меню (ЗАГОТОВКА)

> **Очередь:** после батча куска 2 (`../epic-11-panel-batch-2/spec.md`);
> заготовка, доработать через /spec-prep перед запуском.
> Источник правды — design.md обсуждения dashboard-as-menu-2026-08-23.

## Цель

Заменить текущий сайдбар (с динамическим профилем из Epic-09 фазы 2)
компактной полоской иконок на всех не-дашборд экранах — завершение
замены каркаса навигации, начатой карточками-дверьми.

## Черновые требования

- **FR-1.** Узкая вертикальная полоска иконок слева (~60px), подписи
  при ховере; сверху логотип-«щиток» (возврат на дашборд, выделен),
  внизу аватар; активный раздел подсвечивается.
- **FR-2.** При входе в раздел полоска анимированно разворачивается из
  логотипа вниз («открытие панели»); при переходах между разделами не
  переигрывается; уважает prefers-reduced-motion; реализация дёшево —
  CSS-переход.
- **FR-3.** Текущий сайдбар удаляется со всех экранов; функциональность
  профиля (аватар → profile modal) сохраняется в полоске.

## Заметки

- Отклонены (design.md): верхняя полоска, «вся навигация через
  дашборд», скрытое меню по клику/ховеру.
- На мобильных (Epic-08) полоска превращается в нижнюю панель иконок —
  здесь не делать, но не блокировать.
- Анимация переходов дашборд↔раздел («перелистывание») — Epic-10,
  не этот кусок.

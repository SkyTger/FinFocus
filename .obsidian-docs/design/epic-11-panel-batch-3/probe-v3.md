## Рецидивы (механизмы, чинящиеся ≥3 итерации подряд)
Не обнаружено. Прослежены три кандидата на сквозной механизм через
v1→v2→v3:

- **Идентичность узла (`key`→`id`)**: блокер v1 #1 → закрыт в v2 заменой
  механизма (не переформулировкой) → v3 подтверждает без правок. 2 цикла.
- **Гипотеза FR-2/AC-5 (шаг 0 / план Б)**: блокер v1 #2 → v2 закрывает
  частично (шаг 0 добавлен, но проверяет узел без `id`, тогда как цель —
  узел с `id x` → новая проблема #3 v2) → v3 закрывает (две обязательные
  пробы + полная матрица исходов). 2 цикла правки, к v3 остатка нет.
- **Анимация/`clip-path` и раскадровка эскиза**: замечание v1 #6
  (`fill-mode`+`clip-path` обрезает язычок) → v2 закрывает по букве, но
  порождает новые #1/#2 v2 (расхождение с раскадровкой эскиза, неверная
  арифметика 64px) → v3 закрывает оба (решение владельца Р5 + `calc()`
  вместо магического числа). 2 цикла.

Во всех трёх случаях паттерн — «блокер/замечание → содержательный фикс →
фикс переоткрывает смежный дефект в той же зоне → следующая итерация
закрывает и его», не «один и тот же дефект чинится и не чинится снова».
К v3 ни одна из веток не имеет открытого хвоста — критик v3 прицельно
искал дефекты в зонах точечных правок и не нашёл.

# Brief: User Profile -- Персонализация приложения

## Цель
Реализовать персонализацию приложения: при первом запуске пользователь вводит имя, выбирает аватарку и указывает баланс. Sidebar отображает реальный профиль из БД. Профиль можно редактировать через модал.

## Функциональные требования
- R1: Добавить `avatar_id` (String(20), default="emoji-default") в модель User + миграция 007
- R2: Создать конфиг аватарок `app/config/avatars.py` с 10 emoji-вариантами
- R3: Перестроить Onboarding Wizard -- единый экран с полями: имя (обязательно), аватарка (сетка 10 кликабельных элементов), баланс (опционально)
- R4: Расширить OnboardingService: `complete(user_id, name, avatar_id, starting_balance)` + `update_profile(user_id, name, avatar_id)`
- R5: Sidebar -- динамический профиль из БД (имя + аватарка), с кликом для открытия модала редактирования
- R6: Модал редактирования профиля (глобальный в main.py) -- поля: имя + аватарка (без баланса)
- R7: Dashboard greeting "Добро пожаловать, {имя}!" -- динамическое имя из БД

## Нефункциональные требования
- Glassmorphism Light Theme (glass-card, border-radius: 24px, мятный градиент)
- Совместимость с suppress_callback_exceptions=True (clientside_callback для динамических элементов)
- Идемпотентная миграция 007 (паттерн из migrations.py)
- flush() без commit() в сервисном слое (caller отвечает за commit)

## Ограничения
- Single-user (DEFAULT_USER_ID=1)
- Аватарки ТОЛЬКО предустановленные emoji (не загрузка файлов)
- Баланс НЕ редактируется через модал профиля (только через Сверку)
- Нет страницы /settings или /profile -- только модал

## Критерии приёмки
- [ ] Миграция 007 добавляет avatar_id в users с default "emoji-default"
- [ ] Onboarding wizard показывает поле имени, сетку аватарок и баланс
- [ ] Кнопка "Продолжить" disabled пока имя пустое
- [ ] "Пропустить" сохраняет defaults (name="Пользователь", avatar_id="emoji-default", balance=0)
- [ ] Sidebar отображает реальные name и avatar из БД
- [ ] Клик по профилю в sidebar открывает модал редактирования
- [ ] Модал редактирования сохраняет имя и аватарку, обновляет sidebar
- [ ] Dashboard greeting содержит имя пользователя
- [ ] Bootstrap auto_bootstrap создает User с avatar_id
- [ ] Unit тесты: OnboardingService.complete(), конфиг аватарок, миграция 007

## Вне scope (out of scope)
- Загрузка пользовательских аватарок (фото/файлы)
- Страница /settings или /profile (только модал)
- Многопользовательская архитектура
- Изменение баланса через модал профиля

# Шаг 0: Подготовка и фиксация плана

## Briefing
Этот шаг — технический. Его цель — зафиксировать все созданные файлы плана в первом коммите, опубликовать ветку и создать Pull Request. Все эти действия уже описаны в основном промпте и должны быть выполнены до того, как ты отчитаешься пользователю.

## Sub-tasks
1.  **Создать и сохранить** все артефакты протокола (`plan.md`, `context.md`, `log.md`, `00-setup.md` и файлы для всех последующих шагов) в `.protocols/0001-refactoring/`.
2.  **Сделать первый коммит** с этими файлами в ветку `0001-refactoring`.
3.  **Создать Draft Pull Request** на GitHub.
4.  **Обновить `context.md`**: изменить `Current Step` на `1`, `Status` на `In Progress` и обновить `Next Action` для Шага 1.
5.  **Сохранить** измененный `context.md` **без коммита** (он войдет в коммит следующего шага).

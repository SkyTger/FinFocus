# Шаг 2: Засечки на графике и строка в шапке

## Briefing

- **Цель:** На графике полос видно, где и какие разовые траты; в шапке —
  сколько разовых до узкого места. Оба берут данные из `one_off_marks` /
  `one_off_total_until` шага 1.
- **Ключевые файлы:** `app/components/dashboard.py`
  (`build_layers_chart` :625+, `_build_limit_block` :330+, `LIMIT_HINT`,
  `LAYER_COLORS`), `app/assets/custom.css` (токен `--color-one-off`),
  `app/assets/panel.css` (только класс маркера-кружка, если нужен),
  `tests/test_dashboard_panel_ui.py`.
- **Доп. информация:** состав — plan.md, разделы «График», «Шапка»,
  «Цвет». Полоса «Платежи» остаётся одноцветной — не трогать трассы
  слоёв. Шапка не дверь (тест `test_header_is_not_a_door` остаётся).

## Sub-tasks

1. Токен `--color-one-off: #8e44ad` в `:root` custom.css; константа
   `ONE_OFF_COLOR` в dashboard.py.
2. Трасса «Разовые траты» в `build_layers_chart`: маркеры, hover со
   списком трат дня, подписи у ≤ 3 крупнейших дней
   (`ONE_OFF_LABELS_MAX`). Нет разовых в окне — трассы нет.
3. Строка «Разовые траты до <дата>: N ₽» в `_build_limit_block` с
   кружком цвета разовых; условие показа — plan.md. Дополнить `LIMIT_HINT`.
4. Тесты:
   - трасса есть при разовых в окне, нет без них; число точек = числу
     дней с разовыми; y точки = верх столбца дня; hover содержит
     описания и суммы всех трат дня;
   - подписи: 5 дней с разовыми → ровно 3 подписи, у крупнейших;
     многотратный день → «N траты · сумма»; обрезка длинного описания;
   - трассы слоёв (их число, цвета, данные) не изменились;
   - строка шапки: есть при сумме > 0 и узком месте; нет при 0; дата =
     узкое место; есть и при нехватке;
   - якорный тест: `ONE_OFF_COLOR` == значению `--color-one-off` в custom.css.
5. black / flake8 / pytest.

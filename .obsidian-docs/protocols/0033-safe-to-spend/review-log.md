## 4-m-fix. Вопрос №12 — подушка (решение владельца 2026-11-03: «исправим сразу, потом мерж»)
Решение: порог подушки выходит из резерва совсем — `reserve(t) = goals_part(t)`;
подушка — ориентир: пунктирная линия порога на графике + строка в шапке
«Подушка не добрана: N из T ₽» (N = min(T, свободно сегодня)), не в цвете
риска. Почему именно так (единственный вариант, проходящий все ограничения):
AC2 (нет «0» рядом с лимитом), шапка = зелёный столбик сегодня (AC-1),
`_split_day` — единственный механизм сжатия (п.3б), ответ владельца №3
(подушка наполняется кнопкой, не съедает лимит автоматически). Варианты
«порог в полосе, лимит по жёсткому» (ломает AC2/AC-1), «min(порог, m)»
(лимит 0, пока не набрана — ломает №3), «защищать только набранную» (обрыв
лимита при пересечении порога) — отвергнуты. Отступление от plan.md
(«резерв = порог + цели, правило без изменений») — осознанное, план как
контракт не правим. Бюджет целей остаётся жёстким резервом — осознанно.

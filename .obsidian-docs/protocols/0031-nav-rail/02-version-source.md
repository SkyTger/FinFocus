# Шаг 2: Источник версии

## Briefing

- **Цель:** Завести единственный источник правды о версии, устойчивый к запуску из PyInstaller-бандла. Шаг независим от навигации и мержабелен отдельно.
- **Ключевые файлы:**
  - `app/version.py` — **НОВЫЙ**
  - `app/__init__.py` — сейчас ровно 0 байт, наполняется реэкспортом
  - `tests/test_version.py` — **НОВЫЙ**
- **Доп. информация:** Имя `version.py`, **не** `__version__.py`: иначе `app.__version__` перекрыл бы ссылку на подмодуль и порядок импортов начал бы влиять на то, что за объект получится.

## Sub-tasks

1. Создать `app/version.py` с `__version__ = "0.9.0-beta.1"` и докстрингом (полный текст — solution-v3, «Ключевые интерфейсы»), объясняющим:
   - почему модуль кода, а не data-файл (попадает в PYZ, читается импортом);
   - **условие достижимости**: модуль попадает в бандл ТОЛЬКО пока достижим по статическому графу импортов от `run.py` — сейчас через `run.py → app.main → app.components.profile_modal → from app import __version__`; уберут строку версии из модала — модуль молча выпадет;
   - почему отвергнуты `importlib.metadata` (нет дистрибутива), data-файл (нужен `datas` в спеке), git-тег в рантайме (нет `.git` в бандле);
   - бамп руками одновременно с git-тегом.

2. Наполнить `app/__init__.py`: докстринг с **инвариантом** («в этом файле не появляется ничего, кроме докстринга, реэкспорта версии и `__all__`» — файл выполняется при любом `import app.<...>`, импорт сервисов отсюда даст цикл), `from app.version import __version__`, `__all__ = ["__version__"]`.

3. Создать `tests/test_version.py`:
   - версия непустая и PEP 440-совместимая; не равна `"1.0.0"`;
   - `from app import __version__` совпадает с `from app.version import __version__`;
   - **`test_app_init_contains_only_version_reexport`** — проверять **парсингом AST** (`ast.parse` → в теле модуля ровно один `ImportFrom` и одно присваивание `__all__`, всё прочее — только докстринг), НЕ построчным разбором: текстовая проверка сломается от переформатирования black;
   - **`test_version_matches_git_tag`** — при наличии `.git` и доступного `git` сверяет с `git describe --tags --abbrev=0` (тег `v0.9.0-beta.1` против константы `"0.9.0-beta.1"`), иначе `pytest.skip` (бандл, машина без git). `subprocess` с фиксированными аргументами, без shell;
   - grep по `app/` не находит `v1.0.0` — на этом шаге ещё красный (строка живёт в `sidebar.py:166` до шага 9), пометить `xfail`/активировать после шага 9.

## Workflow

1. Выполни Sub-tasks
2. Базовая проверка: `.venv/bin/python -m py_compile app/version.py app/__init__.py`
3. `.venv/bin/python -m pytest tests/test_version.py -v`
4. Обнови `log.md`, `context.md` (Current Step 3)
5. Коммит: `feat(version): единственный источник версии app/version.py [protocol-0031/02]`
6. Push, отчёт

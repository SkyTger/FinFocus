# Шаг 7: Финализация

## Briefing
- **Цель:** Последний шаг протокола. Проводится полная верификация всего кода перед переводом PR в статус Ready.
- **Ключевые файлы:** Все измененные файлы в рамках протокола
- **Additional info:** На этом шаге проводится полная проверка качества кода (black, flake8, pytest), которая не выполнялась на промежуточных шагах для экономии токенов.

## Sub-tasks

1. **Полная верификация кода:**
   - Запустить black для автоформатирования всех Python файлов: `black .`
   - Запустить flake8 для проверки стиля кода: `flake8 .`
   - Запустить pytest для всех тестов: `pytest`
   - Исправить все найденные проблемы до полного прохождения всех проверок.

2. **Обновить Memory Bank (если нужно):**
   - Добавить описание RedistributionService в `.memory-bank/modules/services.md`
   - Обновить `.memory-bank/index.md` если нужно

3. **Обновить ROADMAP.md:**
   - Отметить "Перераспределение средств между целями" как завершенное
   - Добавить ссылку на PR

4. **Финальный коммит (если были правки):** Если после проверок были внесены исправления, зафиксировать их.

5. **Перевести PR в статус Ready:** Выполнить `gh pr ready` для перевода Draft PR в Ready for Review.

6. **Обновить context.md:** Установить Status: "Completed", Last Action Summary и Next Action.

7. **Финальная фиксация протокола:** Зафиксировать обновленные файлы протокола.

## Workflow (Порядок работы)

**Твоя задача — выполнить `Sub-tasks` выше, строго следуя этому циклу.**

1. **Полная верификация:** Запусти все проверки качества кода последовательно:
   ```bash
   black . && flake8 . && pytest
   ```
   - Если black внес изменения - проверь их.
   - Если flake8 выдает ошибки - исправь их.
   - Если pytest показывает падающие тесты - исправь их.
   - Повторяй проверки, пока все не пройдут успешно.

2. **Коммит правок (если нужно):** Если после проверок были внесены исправления:
   ```bash

   ```
   Сделай пуш.

3. **Перевод PR в Ready:**
   ```bash

   ```

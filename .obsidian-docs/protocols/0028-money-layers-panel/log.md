### Step 03 — Формула резерва по дате D + вехи целей (commit: 0ac3fc2)
- `_goals_part_by_day` реализован буквально по решению:
  `consumed(D)` = Σ savings в [month_start(D), D],
  `committed(D)` = Σ savings в (D, month_end(D)],
  `goals(D) = max(0, budget − consumed − committed)`.
  Месяц берётся ПО ДНЮ D; `committed` НЕ обрезается правым краем окна
  (ключи за `window_end` учитываются — исправление critique-v3 №2)
- Докстринг перенесён целиком: смысл слагаемых + 4 Note (суммирование
  вне окна; данные за границей месяца; вырожденный случай 1-го числа;
  допущение «бюджет не менялся внутри месяца» с обоими направлениями
  ошибки; ограничение перенесённого exception)
- Заглушка снята: `monthly_budget` читается из

# 0007 — Три режима накоплений (Savings Mode)

## ADR-style Summary:

- **Context**: FinFocus позволяет пользователям создавать накопительные цели с автоматическим распределением месячного бюджета (AllocationService). Текущая реализация рассчитывает минимальные взносы точно по графику (100%). Пользователи с разными финансовыми стратегиями хотят гибко управлять интенсивностью накопления.

- **Problem Statement**: Как добавить возможность пользователю выбирать интенсивность накоплений (консервативно vs агрессивно), сохранив простоту интерфейса и обратную совместимость?

- **Decision**: Реализовать три режима накоплений как множители к рассчитанным взносам:
  - `free` (100%) — минимальные взносы точно по графику
  - `medium` (115%) — +15% буфер для страховки
  - `strict` (150%) — максимизация накоплений для раннего достижения цели

  Режим хранится в поле `User.savings_mode` (String), применяется в `AllocationService.calculate_allocation()` как множитель к `monthly_contribution` каждой цели.

- **Alternatives**:
  1. Индивидуальный режим для каждой цели — отвергнуто (усложнение UX для MVP)
  2. Произвольный множитель — отвергнуто (три фиксированных режима понятнее)
  3. SQLAlchemy Enum для savings_mode — отвергнуто (SQLite ALTER TABLE не поддерживает Enum)

- **Consequences**:
  - (+) Гибкость для пользователей с разными стратегиями накопления
  - (+) Простой UI с тремя понятными опциями
  - (+) Обратная совместимость (default="free")
  - (-) Один режим на все цели (MVP ограничение)

## Generic Principles (MUST follow):

### Баланс и простота
- Избегай оверинжиниринга и усложнений
- Не вводи лишних слоёв абстракций
- Доверяй фреймворкам, но обеспечивай требуемую функциональность
- Решения — самые простые из возможных, но качественные и надежные

### Никакого легаси
- Удаляй устаревший код
- Обратная совместимость только через default values
- Все решения — для новой кодовой базы

### Стандарты кодирования (Python 3.12)
- Type annotations обязательны для public API
- Docstrings на русском языке
- Guard clauses в начале функций
- Session management: сервисы используют `flush()`, caller управляет `commit()`
- Форматирование: black + flake8

### Pattern-Matching Callbacks (Dash)
- Проверять `ctx.triggered[0].get('value') is None` для фильтрации автовызовов
- Использовать `prevent_initial_call=True` для модалов

### Качественные тесты
- Тестовое покрытие сбалансировано
- Используй существующие фикстуры из `tests/conftest.py`
- Каждый тест имеет ясное описание того, что проверяется

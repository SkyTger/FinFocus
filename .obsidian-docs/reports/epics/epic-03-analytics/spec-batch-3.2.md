# Спецификация: Батч 3.2 — UX улучшения и Аналитика

**Версия**: 1.0
**Дата**: 2026-01-22
**Статус**: Утверждено
**Зависимость**: Требует завершения Батча 3.1

---

## 1. Бизнес-контекст

### Проблема
После Батча 3.1 категории есть, но:
1. Категоризация вручную утомительна — нужны "быстрые кнопки"
2. Нет визуализации — пользователь не видит структуру расходов
3. Много операций без категории — нужен режим "разобрать хвост"

### Решение
UX улучшения для быстрой категоризации + графики для визуализации.

---

## 2. Скоуп батча

### В скоупе
1. **Быстрые кнопки категорий** — chips в списке транзакций
2. **Режим "разобрать хвост"** — список некатегоризированных + bulk actions
3. **Графики структуры расходов** — donut chart по категориям
4. **Динамика по времени** — bar chart расходов по месяцам/категориям
5. **Экспорт данных** — CSV выгрузка

### НЕ в скоупе (Батч 4+)
- Account модель (несколько кошельков)
- Импорт из банков
- Лимиты по категориям

## 3. Детали реализации

### 3.1 Быстрые кнопки категорий (chips)

**Где:** Список транзакций, под/рядом с каждой строкой без категории

**UX концепция:**
```
┌──────────────────────────────────────────────────────────────────┐
│ 15.01  │ Расход │ -1 500 ₽ │ Кофейня на углу  │ [Без категории] │
│        │        │          │ [Еда] [Развлечения] [Транспорт] ... │
└──────────────────────────────────────────────────────────────────┘
```

**Поведение:**
- Показывать chips только для операций БЕЗ категории
- 5-8 самых частых категорий (по типу операции: income/expense)
- Клик на chip → мгновенно присваивает категорию (без модала)
- Кнопка "..." → открывает полный выбор категорий

**Технические детали:**
- Pattern-Matching Callbacks для chips
- Оптимистичное обновление UI (без перезагрузки всей таблицы)

### 3.2 Режим "разобрать хвост"

**Где:** Отдельный экран или фильтр в списке транзакций

**UX концепция:**
```
┌─────────────────────────────────────────────────────────────────┐
│ Без категории (23 операции)                        [Назад]      │
├─────────────────────────────────────────────────────────────────┤
│ ☐ 15.01  Расход  -1 500 ₽  Кофейня на углу                     │
│ ☐ 14.01  Расход  -3 200 ₽  Яндекс.Такси                        │
│ ☑ 13.01  Расход    -850 ₽  Пятерочка                           │
│ ☑ 12.01  Расход  -1 200 ₽  Магнит                              │
│ ☑ 10.01  Расход    -450 ₽  Пятерочка                           │
├─────────────────────────────────────────────────────────────────┤
│ Выбрано: 3                                                      │
│ Назначить категорию: [Еда и продукты    ▼] [Применить]         │
└─────────────────────────────────────────────────────────────────┘
```

**Поведение:**
- Checkbox для multi-select
- "Выбрать все" / "Снять выбор"
- Dropdown категорий + кнопка "Применить"
- Счетчик выбранных операций
- После применения — операции исчезают из списка

**Технические детали:**
- dcc.Store для хранения выбранных ID
- Bulk update через TransactionService

### 3.3 Графики структуры расходов

**Где:** Dashboard или отдельная страница "Аналитика"

**Donut Chart — структура расходов:**
```
        ┌─────────────────┐
        │    Расходы      │
        │   за январь     │
        │                 │
        │   [DONUT]       │
        │                 │
        │  Всего: 45 000₽ │
        └─────────────────┘

Легенда:
● Еда — 18 000₽ (40%)
● Транспорт — 9 000₽ (20%)
● Жилье — 7 000₽ (15%)
● Развлечения — 5 000₽ (11%)
● Без категории — 6 000₽ (14%)
```

**Технические детали:**
- Plotly `go.Pie` с hole=0.4 (donut)
- Фильтр по периоду (месяц/квартал/год)
- "Без категории" как отдельный сегмент
- Клик на сегмент → фильтрация списка транзакций

### 3.4 Динамика по времени

**Bar Chart — расходы по месяцам:**
```
        Расходы по категориям

   50k │ ████
       │ ████ ████
   25k │ ████ ████ ████
       │ ████ ████ ████ ████
    0  └──────────────────────
         Окт   Ноя   Дек   Янв

        ■ Еда  ■ Транспорт  ■ Жилье  ■ Прочее
```

**Технические детали:**
- Plotly `go.Bar` с группировкой по категориям
- Stacked или grouped (переключатель)
- Период: последние 6/12 месяцев

### 3.5 Экспорт данных (CSV)

**Где:** Список транзакций, кнопка "Экспорт"

**Формат CSV:**
```csv
Дата,Тип,Сумма,Описание,Категория
2026-01-15,expense,-1500,Кофейня на углу,Еда и продукты
2026-01-14,expense,-3200,Яндекс.Такси,Транспорт
2026-01-13,income,50000,Зарплата январь,Зарплата
```

**Поведение:**
- Экспорт с учетом текущих фильтров
- Кодировка UTF-8 с BOM (для Excel)
- Имя файла: `finfocus_transactions_2026-01.csv`

**Технические детали:**
- dcc.Download компонент
- Генерация CSV в callback

## 9. Acceptance Criteria

### Быстрые кнопки
- [ ] Операции без категории показывают chips
- [ ] Клик на chip мгновенно присваивает категорию
- [ ] Кнопка "..." открывает полный выбор

### Режим "разобрать хвост"
- [ ] Можно выбрать несколько операций (checkbox)
- [ ] Bulk action назначает категорию всем выбранным
- [ ] Счетчик некатегоризированных обновляется

### Графики
- [ ] Donut chart показывает структуру расходов
- [ ] Bar chart показывает динамику по месяцам
- [ ] "Без категории" отображается как сегмент
- [ ] Можно менять период (месяц/квартал/год)

### Экспорт
- [ ] Кнопка "Экспорт" скачивает CSV
- [ ] CSV содержит все поля включая категорию
- [ ] Файл корректно открывается в Excel (UTF-8 BOM)

# FinFocus Dashboard UI Specification

**Версия:** 1.0 (2026-02-05)  
**Статус:** Finalized для разработки MVP  
**Контекст:** Desktop-first, светлая тема основная + тёмная опциональная

---

## 1. Архитектура Dashboard

### Макроструктура (desktop 1440px+)
```
┌────────────────────────────────────────────────────────────┐
│  [ Левый сайдбар ]  [ Центральный контент ]  [ Правая ]   │
│  (как единая        (4 KPI-карточки)         колонна       │
│   карточка)                                  (Wishlist +    │
│                     [Дневной график]         Safety        │
│                     месяца 1…31              Cushion)      │
│                                                             │
│                     [2 колонки: операции]                 │
│                     50/50 — Недавние |                     │
│                           Предстоящие                      │
└────────────────────────────────────────────────────────────┘
```

### Левый сайдбар (Главное меню)
- **Единая карточка-контейнер** с фоном, слегка отличающимся от фона страницы.
- **Внутри:** Список пунктов меню (Личные финансы, Баланс, Доходы, Операции, Цели, Настройки).
- **Активный пункт:** подсвечивается зелёным (акцент) бордером или иконкой, вес текста выше.
- **Размер:** ~240px ширина, адаптивно скрывается на мобильных < 576px.

### Верхняя часть Dashboard
**4 KPI-карточки в один ряд:**
- **Total Balance** (текущий остаток кошелька)
- **Income (This Month)** (доходы за месяц)
- **Expense (This Month)** (расходы за месяц)
- **Savings** (накопления/цели)

**Поведение каждой карточки:**
- Заголовок/подпись маленький (12–14px), спокойный серый.
- Главное число крупное (32–40px), полужирное, единый формат денег `15 000 ₽`.
- Дельта или дополнительный KPI маленький (14–16px) рядом/ниже.
- Никаких больших цветных заливок; акцент — тонкая иконка или верхний бордер 2–4px в цвет статуса.
- **CTA на Total Balance:** кнопка/ссылка **«Сверка»** (не "Deposit/Send"), ведёт в модал корректировки баланса с preview.

### Центральный график (дневной казовый календарь)
**Название:** "Операции" / "Кассовый календарь" (над графиком)

**Горизонт:** Месяц (1 число → последнее число текущего месяца).

**Компоненты:**
- **X-ось:** дни месяца 1…N; подписи на кратных 7 (мн. 1, 8, 15, 22, 29…), сегодня подсвечено.
- **Y-ось:** величина сумм; минимум 0, максимум рассчитывается от max(доход+расход).
- **Столбцы (Column bars):** 
  - Доход — зелёный (#2ecc71 light / #27ae60 dark).
  - Расход — красный (#e74c3c light / #c0152f dark).
  - Если в день и доход, и расход, столбцы находят друг на друга (stacked или grouped по выбору), или показывают чистый результат.
- **Линия баланса (Running balance line):** кумулятивный прогнозный остаток за каждый день; толщина 2–3px.
  - Цвет линии по состоянию: **OK** (баланс > 0, нет угрозы) — зелёный; **Attention** (баланс снижается или < 5 000 ₽) — жёлтый; **Risk** (баланс уходит в минус) — красный.
- **Маркер минимума месяца:** кружок/бриллиант на точке минимума баланса, рядом подпись "Мин: дата, сумма".
- **Сетка:** горизонтальные линии очень тихие (opacity 10–15%), вертикальные отсутствуют или еще тише.

**Режим переключения (над графиком, справа):**
- Кнопки/tabs "Месяц" (по умолчанию) и "Год".
- "Год" показывает агрегированный cashflow (столбцы по месяцам, линия среднего баланса).

**Интерактивность (hover/click):**
- Наведение на день → появляется tooltip с датой, доходом, расходом, балансом.
- Клик на день → открывает глобальный модал создания операции с предвыбранной датой (или переход в Calendar).

### Правая колонна (Wishlist + Safety Cushion)
**Две карточки, одна под другой:**
- **Wishlist (Отложенные покупки):** список из 5 позиций (приоритет, название, сумма, дата планирования); кнопка "Показать все" внизу → Операции.
- **Safety Cushion:** текущие параметры подушки безопасности, сценарии (сумма, расчёты), может быть свёрнута/развёрнута.

**Стиль:** одинаковая высота, одинаковые бордеры/тени, визуально равноправны.

### Нижняя часть Dashboard (2 колонки 50/50)
**Левая колонка: "Недавние операции"**
- Показывает операции с **1 числа текущего месяца по сегодня (включительно)**.
- **Максимум 5 строк** (таблица/список).
- Столбцы: Дата | Описание/категория | Сумма.
- Без бейджей "Completed"; категория или тип (повторяющаяся ⟳) во вторую строку.
- Сумма выравнивается вправо, формат `15 000 ₽`, отрицательные со знаком и цветом Risk.
- Внизу: ссылка **«Все операции: с 1 по сегодня»** → /operations с фильтром дат.

**Правая колонка: "Предстоящие операции"**
- Показывает операции с **сегодня по конец месяца (включительно)**.
- **Максимум 5 строк**.
- Та же структура (Дата | Описание | Сумма).
- Внизу: ссылка **«Все операции: сегодня → конец месяца»** → /operations с фильтром дат.

**Состояния:**
- Нет данных: пустое состояние с иконкой, текст "Нет операций", опционально CTA "Добавить".
- Мало данных: показываем те, что есть.
- Данные после редактирования: обновляются сразу (глобальный Refresh Trigger).

## 2. Цветовые роли (семантика)

### Светлая тема (основная)
**Палитра:**
- **Primary (Accent) — Зелёный:** `#2ecc71` (яркий) или `#27ae60` (темнее для текста/иконок).
  - Используется: OK-состояния, доходы, primary CTA, активные пункты меню.
- **Secondary — Синий:** `#3498db` (основной) или `#2980b9` (темнее).
  - Используется: ссылки, secondary CTA, вторичные элементы навигации.
- **Income — Зелёный:** `#27ae60` (столбцы графика, иконки доходов).
- **Expense — Красный:** `#e74c3c` (столбцы графика, иконки расходов).
- **Status — Attention:** `#f39c12` (жёлтый; баланс < 5 000 ₽).
- **Status — Risk:** `#c0152f` (красный; баланс отрицательный).
- **Neutral/Text:** `#2c3e50` (очень тёмный для текста), `#95a5a6` (серый для подписей), `#ecf0f1` (очень светлый для фона).
- **Surface (карточки):** `#ffffff` (белый) с тонким бордером `1px solid #bdc3c7` или лёгкой тенью `0 2px 8px rgba(0,0,0,0.08)`.

**Фон страницы:** `#f8f9fa` (очень светлый серый).

### Тёмная тема (опциональная, "Data-first")
**Палитра:**
- **Primary (Accent) — Зелёный:** `#2ecc71` (сохраняется), но может быть чуть приглушеннее `#1abc9c` на тёмном.
- **Secondary — Синий:** `#3498db` (светлее для тёмного фона, может быть `#5dade2`).
- **Income — Зелёный:** `#1abc9c` или `#16a085` (для столбцов, может быть чуть светлее).
- **Expense — Красный:** `#e74c3c` (сохраняется, или `#c0392b` ещё темнее).
- **Status — Attention:** `#f39c12` (жёлтый, может быть `#f1c40f` светлее).
- **Status — Risk:** `#e74c3c` (красный, как в light, но на тёмном смотрится ярче).
- **Neutral/Text:** `#ecf0f1` (очень светлый, почти белый для основного текста).
- **Text — Secondary:** `#bdc3c7` (светлый серый для подписей).
- **Surface (карточки):** `#34495e` (тёмный слейт) с тонким бордером `1px solid #2c3e50` (без glow, без свечения по периметру).

**Фон страницы:** `#1e272e` или `#0f1823` (очень тёмный, почти чёрный).

**Кол-во свечений в тёмной теме:** минимум — только на hover активных элементов и статус-маркерах (Risk, минимум баланса). Glow по периметру карточек **запрещён** для снижения шума.

## 3. Типографика и формат денег

### Шкала размеров
- **Hero-число (KPI):** 40px, semibold/bold, `#2c3e50` (light) / `#ecf0f1` (dark).
- **Заголовок карточки:** 16px, medium, `#95a5a6` (light) / `#bdc3c7` (dark).
- **Подпись/период:** 12px, regular, `#95a5a6` (light) / `#bdc3c7` (dark).
- **Число в таблице:** 14–16px, regular, `#2c3e50` (light) / `#ecf0f1` (dark), выравнивание RIGHT.
- **Описание/категория в таблице:** 13px, regular, `#7f8c8d` (light) / `#95a5a6` (dark).
- **Ссылка "Показать все":** 13px, semibold, цвет Secondary (синий), с underline на hover.

### Формат денег
- **Основной:** `15 000 ₽` (пробел как разделитель тысяч, символ ₽ в конце).
- **Дельта с плюсом:** `+2 350 ₽` (зелёный, OK-статус).
- **Дельта с минусом:** `−1 200 ₽` (красный Risk-статус; знак минус **обязателен**, цвет усиливает).
- **Без дельты:** просто число, цвет зависит от типа (доход/расход/баланс).

## 4. Компоненты и микровзаимодействия

### KPI-карточка
```
┌─────────────────────────┐
│ 📊 Баланс               │  ← заголовок 12px, серый
│                         │
│ 45 000 ₽                │  ← число 40px, bold, чёрный
│                         │
│ +2 350 vs вчера         │  ← подпись 12px, серый
│                         │
│ [ Сверка ]              │  ← CTA (только на Total Balance)
└─────────────────────────┘
```
- **Карточка:** белая (`#fff`), бордер `1px solid #bdc3c7` ИЛИ тень `0 2px 8px rgba(0,0,0,0.08)` (не одновременно).
- **Радиус:** 8–10px.
- **Padding:** 20px.

### Список операций (таблица)
```
┌──────────────┬─────────────────┬──────────────┐
│ Дата         │ Описание         │ Сумма        │
│ 5 февраля    │ Продукты 🛒      │ −2 500 ₽     │
│              │ (категория)      │ (красный)    │
├──────────────┼─────────────────┼──────────────┤
│ 4 февраля    │ Зарплата ⟳       │ +50 000 ₽    │
│              │ (повторяющаяся)  │ (зелёный)    │
└──────────────┴─────────────────┴──────────────┘
```
- **Строка высота:** 48–56px (две строки текста).
- **Сумма выравнивание:** RIGHT.
- **Hover:** лёгкий фон `rgba(0,0,0,0.02)` (light) / `rgba(255,255,255,0.02)` (dark).
- **Separator:** `1px solid #ecf0f1` (light) / `1px solid #2c3e50` (dark).

### Ссылка "Показать все"
- **Стиль:** `13px semibold`, цвет Secondary (синий `#3498db`).
- **Hover:** underline, цвет темнее `#2980b9`.
- **Текст:** точно "Все операции: с 1 по сегодня" или "Все операции: сегодня → конец месяца", дата-диапазон **явный**.

### Кнопка "Сверка" (на Total Balance)
- **Стиль:** Primary (зелёный `#2ecc71`), белый текст, padding 10px 16px, border-radius 6–8px.
- **Hover:** фон темнеет до `#27ae60`.
- **Click:** открывает глобальный модал с полем ввода суммы (фактический баланс) и preview (разница, тип коррекции).

## 5. Модал корректировки баланса (Сверка)

### Структура
1. **Заголовок:** "Сверка баланса"
2. **Текущий остаток:** показываем из системы (read-only, серый).
3. **Поле ввода:** "Фактический баланс" (обязательное, число), placeholder "Введите сумму".
4. **Preview (перед подтверждением):** разница = фактический − текущий; показываем, создаётся ли `+` или `−` корректировка.
5. **Кнопки:** "Подтвердить" (зелёный), "Отмена" (серый).

### Поведение
- **Безопасность:** preview обязателен; пользователь видит, что будет создана корректирующая запись типа ADJUSTMENT. [file:2]
- **После подтверждения:** метрики на Dashboard обновляются сразу (Refresh Trigger Pattern), новая операция видна в "Недавних операциях".

## 6. Состояния и обновления

### Пустое состояние (нет операций)
```
┌─────────────────────────┐
│                         │
│        📭               │
│   Нет операций          │
│                         │
│   [ Добавить ]          │
│                         │
└─────────────────────────┘
```

### Состояние после CRUD
- После добавления/редактирования операции на любой странице (Calendar, Transactions, через Quick-add) Dashboard **автоматически** обновляет:
  - Метрики (Total Balance, Income, Expense, Savings).
  - График (столбцы, линия баланса, маркер минимума).
  - Список операций (5 последних или предстоящих).
- Механизм: **Refresh Trigger Pattern** (глобальный Store), без перезагрузки страницы.

### Состояние "есть риск"
- Если минимум баланса месяца < 0 (Risk) или < 5 000 ₽ (Attention):
  - На KPI "Total Balance" показываем бейдж/иконка Warning.
  - На графике линия баланса окрашивается в жёлтый/красный.
  - Маркер минимума подсвечивается красным.

## 7. Правила плотности и отступов

### Desktop (1440px)
- **Основной контент ширина:** 1200px (max-width).
- **Gap между колонками:** 24px.
- **Padding контейнера:** 16–20px.
- **Внутренний padding карточек:** 20px.
- **Margin между блоками:** 24px (верт.) / 16px (гориз.).

### Планшет (768–1023px)
- Правая колонна (Wishlist + Safety) может уходить ниже.
- Левый сайдбар сужается до 200px или становится выдвижным (menu).
- 2-колонка внизу становится single-column или 60/40.

### Мобильный (<576px)
- Сайдбар скрывается (hamburger menu).
- Верхние 4 KPI горизонтальный scroll.
- График на весь экран, не масштабируется вверх.
- 2-колонка операций — single-column с табами (Недавние | Предстоящие).

## 8. Acceptance Criteria (Готовность дизайна)

### Visual
- [ ] На Dashboard за 1 секунду видно: текущий Total Balance и статус прогноза (OK/Attention/Risk) по цвету маркера минимума.
- [ ] График Month показывает дни 1…N: столбцы доход (зелёный) / расход (красный) + линия баланса (зелёный/жёлтый/красный по статусу).
- [ ] Минимум месяца отмечен маркером и датой; рядом/в tooltip — сумма минимума.
- [ ] Числа единый формат `15 000 ₽`, отрицательные со знаком `−` и цветом Risk.
- [ ] Карточки KPI выглядят одинаково: белые, с бордером или тенью, без цветных заливок на основном фоне.
- [ ] Wishlist и Safety Cushion визуально равноправны (одна ширина, один стиль).
- [ ] Левый сайдбар одна карточка-контейнер с пунктами меню; активный пункт подсвечен зелёным.
- [ ] Списки операций компактные (2 строки на элемент), без "Completed", категория/тип во вторую строку.

### UX
- [ ] "Показать все" ведёт на Операции с явным диапазоном дат (1…сегодня для Недавних, сегодня…конец для Предстоящих).
- [ ] Кнопка "Сверка" на Total Balance открывает модал с preview коррекции.
- [ ] После добавления/редактирования операции Dashboard обновляется сразу (Refresh Trigger).
- [ ] Клик на день графика открывает модал создания операции или переход в Calendar.
- [ ] Переключатель Month/Year работает без перезагрузки страницы.
- [ ] Нет данных → пустое состояние с CTA "Добавить".

### Тёмная тема
- [ ] Все цветовые роли сохраняются (доход зелёный, расход красный, риск красный).
- [ ] Контраст текста достаточен для чтения чисел без проблем (WCAG AA минимум).
- [ ] Glow и свечения **отсутствуют** на карточках (только на hover/focus активных элементов).
- [ ] График остаётся читаемым: сетка очень тихая, линия баланса — главный акцент.

## 9. Механика разработки (для FE)

### Компоненты
1. **KPICard** — переиспользуемая карточка для метрик.
2. **CashflowChart** — Plotly/Recharts график с режимами Month/Year.
3. **OperationsTable** — таблица 5 рядов + ссылка "Показать все".
4. **ReconciliationModal** — модал сверки баланса.
5. **Sidebar** — навигация в card-контейнере.

### Stores/State
- **dashboard-refresh-trigger:** глобальный сигнал об обновлении после CRUD.
- **date-range:** диапазон дат для фильтра на странице Операции.

### API/Services
- `DashboardService.getMetrics()` — Total Balance, Income, Expense, Savings.
- `CalendarService.getDailyBalances(month, year)` — прогноз остатков по дням.
- `TransactionService.getRecent(fromDate, toDate)` — операции за период.
- `ReconciliationService.createAdjustment(balance)` — создание корректирующей записи.

## 10. Миграционный путь (если переделываем существующий Dashboard)

1. **Шаг 1:** Обновить цветовые переменные (зелёный, синий, красный, статусы).
2. **Шаг 2:** Переделать KPI-карточки — убрать цветные заливки, добавить бордер/тень.
3. **Шаг 3:** Обновить график — добавить линию баланса, маркер минимума, изменить оси/сетку.
4. **Шаг 4:** Переработать списки операций — убрать "Completed", добавить вторую строку для категории.
5. **Шаг 5:** Оформить левый сайдбар как card-контейнер.
6. **Шаг 6:** Добавить модал сверки баланса с preview.
7. **Шаг 7:** Реализовать Dark theme как CSS-переменные, не как отдельный дизайн.
8. **Шаг 8:** QA и итеративная доводка по скринам (light + dark).

## 11. Глоссарий и сокращения

- **KPI:** Key Performance Indicator (метрика).
- **CTA:** Call To Action (кнопка/ссылка действия).
- **CRUD:** Create, Read, Update, Delete.
- **Refresh Trigger Pattern:** глобальный Store сигнал об обновлении.
- **ADJUSTMENT:** тип операции, корректирующая запись (сверка баланса).
- **Wishlist:** отложенные покупки (запланированные, с датой и безопасностью).
- **Safety Cushion:** подушка безопасности (минимальный остаток).
- **Monthly Savings Budget:** распределение бюджета по целям.

---

**Документ финализирован.** Все соглашения по структуре, цветам, типографике и поведению зафиксированы. Готов к передаче дизайнер-сайде и фронтенд-разработке.

# Шаг 6: Финализация

## Briefing
- **Цель:** Последний шаг протокола. Проводится полная верификация всего кода перед переводом PR в статус Ready.
- **Ключевые файлы:** Все измененные файлы в рамках протокола
- **Additional info:** На этом шаге проводится полная проверка качества кода (black, flake8, pytest), которая не выполнялась на промежуточных шагах для экономии токенов.

## Sub-tasks

1. **Полная верификация кода:**
   - Запустить black для автоформатирования: `black .`
   - Запустить flake8 для проверки стиля: `flake8 app/ tests/`
   - Запустить pytest для всех тестов: `pytest -v`
   - Исправить все найденные проблемы до полного прохождения всех проверок.

2. **Проверить работоспособность приложения:**
   - Запустить `python run.py`
   - Открыть http://localhost:8050/goals
   - Проверить что selector режима отображается
   - Проверить что смена режима пересчитывает allocation

3. **Финальный коммит (если были правки):**
   - Если после проверок были внесены исправления, зафиксировать их.

4. **Перевести PR в статус Ready:**
   - Выполнить `gh pr ready` для перевода Draft PR в Ready for Review.

5. **Обновить context.md:**
   - Установить Status: "Completed"
   - Last Action Summary: "Финализация завершена"
   - Next Action: "Протокол завершен. Ожидается code review и merge."

6. **Финальная фиксация протокола:**
   - Зафиксировать обновленные файлы протокола.

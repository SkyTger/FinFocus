# Epic-03: Analytics & UX

## Цель эпика

Добавить аналитические возможности для понимания "куда уходят деньги" и улучшить UX работы с операциями, сохранив главную ценность FinFocus — кассовый календарь и планирование будущего.

## Философия

**FinFocus — про будущее**, а категоризация прошлых операций — вспомогательный инструмент:
- Кассовый календарь требует точных сумм для прогноза
- Категории дают "примерную картину" для анализа
- Полный учет каждой копейки **не требуется**

**Ленивая категоризация**: категория не обязательна при вводе. "Без категории" — нормальное состояние.

**Сверка (Reconciliation)**: механизм синхронизации модели с реальностью без необходимости помнить каждую мелкую трату.

## Метрики успеха

- Пользователь может видеть структуру расходов по категориям

- Категоризация не блокирует ввод операций
- Аналитика работает даже при 50% покрытии категориями

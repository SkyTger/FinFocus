# Epic-09: Подготовка к бета-тестированию

## 🎯 Цель

Устранить технические блокеры и обеспечить дружелюбный первый запуск приложения для нетехнических пользователей (бета-тестеры).

## 📊 Scope

### Входит:
- Автоматическая инициализация пользователя и категорий при первом запуске
- Welcome screen с созданием профиля (имя + аватарка)
- Отображение профиля в sidebar
- Страница/модал редактирования профиля
- Набор предустановленных аватарок (8-12 emoji/иконок)
- Отключение debug mode по умолчанию
- README для тестеров с пошаговой инструкцией

### Не входит:
- Многопользовательская архитектура (остаётся single-user, DEFAULT_USER_ID=1)
- Загрузка пользовательских аватарок (только предустановленные)
- Docker, PyInstaller, setup-скрипт (отдельная фаза — scope TBD)
- Изменение способа установки (git clone + pip install + python run.py)

## 🔍 Предыстория

**Проблема**:
Аудит проекта выявил следующие блокеры для бета-тестирования:

1. **Нет автосоздания пользователя**: Весь код использует `DEFAULT_USER_ID=1`, но при первом запуске User(id=1) не существует → приложение крашится
2. **Категории не сидятся автоматически**: `scripts/seed_categories.py` нужно запускать вручную → технический барьер для нетехнических пользователей
3. **Debug mode включён по умолчанию**: `DEBUG=True` в run.py → детальные ошибки видны пользователям
4. **Нет персонализации**: Пользователь не может задать своё имя и аватарку → обезличенный опыт

**Решение**:
- Приложение для ЛОКАЛЬНОГО использования (каждый тестер ставит себе)
- Автоматическая инициализация при первом запуске: User(id=1) + 16 категорий + миграции
- Welcome screen (первый запуск): ввод имени + выбор аватарки
- Аватарки: готовый набор из 8-12 предустановленных emoji/иконок (НЕ загрузка файлов)
- Single-user архитектура сохраняется (DEFAULT_USER_ID=1)
- Способ установки/доставки: обсуждается позже (Фаза 3 — scope TBD)

### Auto-bootstrap логика (Фаза 1):
```python
# run.py (до app.run_server)
def auto_bootstrap():
    """Автоинициализация для первого запуска."""
    with get_db_session() as session:
        # 1. Создать User(id=1) если нет
        if session.query(User).count() == 0:
            default_user = User(
                id=1,
                email="user@local",
                name="Пользователь",
                avatar_id="emoji-smile"
            )
            session.add(default_user)
            logger.info("Создан пользователь по умолчанию (id=1)")

        # 2. Seed категорий если нет
        if session.query(Category).count() == 0:
            seed_categories(session)
            logger.info("Добавлено 16 предустановленных категорий")

        session.commit()

    # 3. Запустить миграции
    run_all_migrations()
```

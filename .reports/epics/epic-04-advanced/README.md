# Epic-04: Advanced Features

## Цель эпика

Добавить дополнительные возможности для готовности к запуску MVP — автоматизация частых операций, финансовая подушка безопасности, импорт данных и улучшение онбординга.

## Философия

**FinFocus — про удобство и минимум усилий**:
- Частые операции должны вводиться за 1-2 клика
- Система автоматически помогает создавать финансовую подушку
- Импорт данных экономит время на начальном заполнении
- Онбординг упрощает первое знакомство с приложением

**Quick-add chips**: максимально упростить ежедневный ввод операций — один клик для частых категорий и шаблонов.

**Финансовая подушка**: автоматическое направление неосвоенного остатка бюджета накоплений на безопасность.

## Батчи

### Батч 4.1: Quick-add Chips (фаза A + B)
**Статус**: Планируется
**Цель**: Ускорить ввод операций через частые категории и шаблоны
**Оценка**: ~12-16 дней

**Протокол A** (~6-8 дней):
- Чипы категорий (дефолтные 5 расход + 2 доход)
- Клик на chip → модал создания операции с предвыбранной категорией
- UI: плитки с иконками под кнопками "Экспорт" и "Добавить"

**Протокол B** (~6-8 дней):
- Шаблоны операций (name, category, amount, description)
- 1-клик создание операции из шаблона (toast "Отменить")
- Кастомизация чипов (добавление/удаление/порядок/архивирование)

Детали: `spec-quick-add-chips.md`

## Метрики успеха

### Quick-add chips:
- Время добавления частой операции < 5 секунд
- 70% пользователей используют chips вместо полной формы
- Retention rate увеличивается на 15% (из-за снижения friction)

### Финансовая подушка:
- 50% пользователей активируют подушку в первый месяц
- Средний размер подушки: 2-3 месяца расходов

### Импорт данных:
- Время первого заполнения операций < 10 минут (вместо часов)
- 80% успешных импортов без ошибок

### Онбординг:
- Время до первой цели < 10 минут
- Завершение онбординга > 80% новых пользователей

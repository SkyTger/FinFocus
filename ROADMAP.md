# ROADMAP MVP - Планировщик бюджета

Поэтапный план разработки MVP приложения для планирования личного и семейного бюджета.

## Общая стратегия

MVP разрабатывается по принципу **dual-track agile** с параллельным Discovery (валидация UX) и Delivery (реализация функций). Каждый батч представляет собой вертикальный срез функциональности с полноценным пользовательским опытом.

### Принципы приоритизации (MoSCoW)
- **Must Have**: Кассовый календарь, базовый дашборд, одна цель накопления
- **Should Have**: Повторяющиеся операции, несколько целей, режимы накоплений  
- **Could Have**: Категории расходов, финансовая подушка, импорт данных
- **Won't Have**: AI-рекомендации, интеграции с банками, мобильные приложения

## Временные рамки
- **Общее время разработки MVP**: 16-20 недель
- **Количество батчей**: 5 
- **Средняя продолжительность батча**: 3-4 недели

## Риски и митигация

**Высокие риски**:
- Сложность кассового календаря с повторяющимися операциями
- Пользовательское принятие концепции целевого бюджетирования
- Конкуренция с установленными игроками рынка

**Стратегии снижения рисков**:
- Ранние прототипы движка с юнит-тестами
- Непрерывная валидация через пользовательские интервью
- Фокус на уникальную ценность (кассовое планирование + цели)

## Метрики успеха MVP

**Продуктовые метрики**:
- Время до первой добавленной цели < 10 минут
- Retention rate 30 дней > 25%
- Активность: > 3 сессий/неделю в первый месяц

**Технические метрики**:
- Время загрузки календаря < 2 сек
- Упtime > 99%
- 0 критических багов в production

**Бизнес метрики**:
- CAC < $50 для ранних пользователей
- Готовность платить > 60% после trial
- Вирусность: > 15% пользователей приглашают других

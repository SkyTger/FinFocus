# Планировщик бюджета

Инструмент планирования личного и семейного бюджета с возможностью проактивного планирования накоплений на крупные цели.

## Основные возможности

### Финансовый учёт
- Ведение доходов и расходов с привязкой к датам
- Поддержка повторяющихся операций (зарплата, коммунальные платежи)
- Категоризация трат с визуальными индикаторами
- Автоматический расчёт остатков на любую дату

### Кассовый календарь
- Календарное представление всех финансовых операций
- Визуальная индикация дат поступлений и платежей
- Прогноз остатков с учётом запланированных операций
- Удобное добавление новых операций прямо в календаре

### Планирование целей
- Создание накопительных целей с датами реализации
- Автоматический расчёт необходимых ежемесячных взносов
- Три режима накоплений: свободный, средний, строгий
- Перераспределение средств при достижении ближайших целей

### Визуализация и аналитика
- Дашборд с ключевыми финансовыми показателями
- Графики динамики доходов и расходов
- Отслеживание прогресса по накопительным целям
- Анализ структуры расходов по категориям

## Уникальные особенности

**Кассовое планирование**: В отличие от стандартных бюджетных приложений, система строится вокруг точных дат операций, что позволяет видеть реальные остатки на любой день и избегать кассовых разрывов.

**Умное распределение по целям**: При наличии нескольких накопительных целей система автоматически рассчитывает оптимальное распределение средств с приоритетом на ближайшие дедлайны.

**Режимы накоплений**: Поведенческие настройки (строгий/средний/свободный), которые влияют на размер рекомендуемых взносов и помогают поддерживать финансовую дисциплину.

**Финансовая подушка**: Автоматические рекомендации по формированию резерва из свободных средств.

## Целевая аудитория

- Семьи, планирующие крупные покупки (недвижимость, автомобиль, отпуск)
- Люди с нерегулярными доходами, которым важно видеть остатки на конкретные даты
- Пользователи, которые хотят совместить текущее планирование с долгосрочными накоплениями
- Те, кто ищет более структурированный подход к целевым сбережениям

## Технологический стек

Приложение разрабатывается как веб-приложение с адаптивным интерфейсом, подходящим для использования на настольных и мобильных устройствах.

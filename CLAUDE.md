# CLAUDE.md  

Этот файл задаёт правила работы ИИ‑ассистента с репозиторием: где смотреть планы, как предлагать изменения и как обновлять статусы задач. Цель — воспроизводимый процесс «план → батч → проверка → фиксация прогресса» [источник: лучшие практики Claude Code].  

## Что читать при старте  
- @ROADMAP.md — единый источник задач и приоритетов (читать в начале каждой сессии).  
- @.reports/notes/feature_progress.md — краткие итоги по активной фиче/батчу (если есть).  
- Конфиги и качество: @.flake8, @.editorconfig, @requirements.txt, @.gitlab-ci.yml.  

## Процесс (план → батч)  
- План‑режим (без правок кода):  
- Прочитать ROADMAP.md и предложения в feature_progress.md.  
- Сформировать «План батча» (1–3 файла максимум) с перечнем действий и ожидаемым эффектом.  
- Ждать подтверждения.  
- Батч‑режим (после подтверждения):  
- Редактировать только согласованные файлы.  
- Показать диффы, выполнить скрипты качества (./scripts/run_lint.sh, pytest … — если указано).  
- По завершении — обновить ROADMAP.md и feature_progress.md.  
- Ограничения:  
- Не править файлы вне списка текущего батча.  
- Длинные списки/логи сохранять в .reports/notes/*.md, а не в чат.  

## Управление ROADMAP.md  
- Формат чекбоксов:  
- [ ] Todo — запланировано  
- [-] In Progress — в работе; добавить дату начала (YYYY/MM/DD)  
- [x] Done — выполнено; добавить дату завершения (YYYY/MM/DD) и ссылку на коммит/PR  
- Разделы:  
- High Priority — ближайшие 3–5 задач.  
- Backlog — идеи и будущие задачи.  
- Recently Completed — завершённые пункты с датами/ссылками.  
- Обновление ассистентом:  
- При старте: прочитать ROADMAP.md и предложить «Следующий шаг» из High Priority.  
- После принятого батча: пометить пункт как [x] Done, перенести в Recently Completed, добавить 1–2 строки итога и ссылку на коммит/PR.  
- Обновления можно делать только в @ROADMAP.md и @.reports/notes/*.md (исходники — отдельно, по батчам).  

## Правила качества и стиля  
- Стиль кода: @.flake8, @.editorconfig, Python 3.12, аннотации типов обязательны.  
- Документация функций/классов: краткий docstring на русском.  
- Приоритет исправлений flake8:  
1) F‑категория (например, F401)  
2) E‑категория (например, E701, E226)  
3) W‑категория (например, W293, W292)  
- Изменения минимальные, без изменения поведения. Обязательное дифф‑ревью перед записью.  

## Контекст и артефакты  
- Долгоживущие решения — docs/adr/*.md (Architecture Decision Records). ROADMAP.md может ссылаться на ADR.  
- Крупные фичи — .reports/notes/feature_<slug>_plan.md и feature_progress.md (краткие итоги по батчам). 

## Стандарты разработки 
- Ветки: feature/..., bugfix/..., hotfix/...  
- Коммиты: «тип: краткое_описание» (например, feat: add user resolver)  
- Секреты не хранить в коде. Не использовать глобальные переменные.  

## Контекст проекта  
- Python 3.12

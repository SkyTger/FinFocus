# Brief: Goals UI - Накопительная цель с расчетом взносов

## Цель
Реализовать полнофункциональный UI для управления накопительной целью (Фаза 5 Core MVP), позволяющий пользователю создавать цель, вносить деньги и отслеживать прогресс накопления с рекомендованным ежемесячным взносом.

## Функциональные требования
- FR-01: Отображение текущей активной цели с прогресс-баром и ключевыми метриками
- FR-02: Создание новой цели через модальную форму (название, целевая сумма, дедлайн)
- FR-03: Внесение взносов в цель через модальную форму (сумма, дата, описание)
- FR-04: Отображение рекомендованного ежемесячного взноса (формула: (target - current) / months_remaining)
- FR-05: Редактирование параметров цели (название, целевая сумма, дедлайн)
- FR-06: Удаление цели с подтверждением
- FR-07: Отображение истории взносов (последние N записей)
- FR-08: Смена статуса цели (ACTIVE/PAUSED/COMPLETED)

## Нефункциональные требования
- NFR-01: Следовать паттернам из transactions.py (модалы, callbacks, guard clauses)
- NFR-02: Применять ADR-003 guard clauses для Pattern-Matching Callbacks
- NFR-03: Docstrings на русском языке, type annotations обязательны
- NFR-04: Unit тесты для новой логики сервисов (если добавляется)
- NFR-05: Стили в отдельном CSS файле (goals.css) по аналогии с calendar.css

## Ограничения
- MVP: только одна активная цель на пользователя (валидация в GoalService уже реализована)
- Hardcoded user_id=1 (как в transactions.py и dashboard.py)
- Дедлайн цели минимум через 7 дней от сегодня (валидация в GoalService)

## Критерии приёмки
- [ ] Страница /goals отображает активную цель с прогресс-баром
- [ ] Пользователь может создать цель через модальную форму
- [ ] Пользователь может добавить взнос в цель
- [ ] Отображается рекомендованный ежемесячный взнос
- [ ] Пользователь может редактировать/удалить цель
- [ ] История взносов отображается в таблице/списке
- [ ] Все callbacks работают без регрессий (guard clauses применены)
- [ ] Код проходит black + flake8 без ошибок
- [ ] Unit тесты проходят (33+ тестов)

## Вне scope (out of scope)
- Множественные цели с приоритетами (Батч 2)
- Три режима накоплений (свободный/средний/строгий) (Батч 2)
- Перераспределение средств между целями (Батч 2)
- Связь взносов с транзакциями (автоматическое списание)
- Графики динамики накоплений (Батч 3)

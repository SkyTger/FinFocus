# Brief: Множественные накопительные цели с приоритетами

## Цель
Реализовать поддержку множественных накопительных целей с системой приоритетов и расчетом рекомендуемых взносов, чтобы пользователь мог одновременно откладывать на несколько целей с автоматическим распределением рекомендуемых сумм.

## Функциональные требования

### FR-1: Снятие ограничения D009 (одна активная цель)
- Пользователь может создавать неограниченное количество активных целей
- При создании новой цели ограничение `active_goals_count >= 1` удаляется из GoalService.create_goal()

### FR-2: Приоритеты целей
- Каждая цель имеет числовой приоритет (1 = самый важный, далее 2, 3...)
- Приоритет задается при создании цели и редактируется
- При создании новой цели по умолчанию назначается приоритет = (max существующих + 1)
- Возможность изменить порядок приоритетов через UI (drag-and-drop или ручной ввод)

### FR-3: Расчет рекомендуемых взносов с учетом приоритетов
- Пользователь указывает общую доступную сумму для накоплений (monthly_savings_budget)
- Система рассчитывает распределение между целями по формуле:
  - Приоритет 1 получает максимально возможный взнос (до monthly_contribution цели)
  - Остаток распределяется на цели с приоритетом 2, 3 и т.д.
- Показывается breakdown: сколько на каждую цель
- Предупреждение если бюджета недостаточно для всех целей в срок

### FR-4: UI для множественных целей
- Список всех активных целей (карточки или таблица) с сортировкой по приоритету
- На каждой карточке: название, прогресс-бар, рекомендуемый взнос, дедлайн
- Кнопки действий: редактировать, приостановить, удалить
- Модал создания цели с полем приоритета (или автоназначение)
- Модал быстрого взноса в любую цель
- Сводная секция: общий прогресс накоплений, общая сумма накоплена/целевая

### FR-5: Интеграция с Dashboard
- Показывать сводку по всем активным целям (не только первой)
- Общий savings progress = сумма по всем целям

## Нефункциональные требования

### NFR-1: Производительность
- Загрузка страницы Goals с 10+ целями < 1 секунда
- Расчет рекомендуемых взносов мгновенный (no spinner)

### NFR-2: Backward Compatibility
- Существующие цели с priority=1 сохраняют работоспособность
- Миграция не требуется (поле priority уже есть в модели)

### NFR-3: Тестирование
- Unit тесты для новых методов GoalService (min 10 тестов)
- Тесты логики распределения взносов

## Ограничения

### Технические
- SQLite база данных (без сложных оконных функций)
- Dash framework (callbacks-based UI)
- Существующая структура сервисов (GoalService pattern)
- Поле Goal.priority уже существует в модели (Integer, default=1)

### Бизнес-ограничения
- Три режима накоплений (свободный/средний/строгий) — отдельная задача, не в этом scope
- Перераспределение средств между целями — отдельная задача (Batch 2)

## Критерии приёмки

- [ ] Пользователь может создать 3+ активных цели одновременно
- [ ] Цели отображаются в порядке приоритета (1 первый)
- [ ] Изменение приоритета цели работает через UI
- [ ] Расчет распределения взносов корректно учитывает приоритеты
- [ ] Dashboard показывает сводку по всем активным целям
- [ ] Unit тесты покрывают новую логику распределения (min 10)
- [ ] Существующие тесты проходят без регрессий

## Вне scope (out of scope)

- Режимы накоплений (свободный/средний/строгий) — Batch 2, следующая задача
- Автоматическое перераспределение при недостижении цели — Batch 2
- Drag-and-drop для изменения порядка приоритетов — nice-to-have, можно заменить полем ввода
- История изменений приоритетов
- Уведомления о недостаточном бюджете накоплений

# Brief: Day Tooltip with Glassmorphism Style for Cash Calendar

## Цель
Реализовать интерактивный tooltip для ячеек дней календаря, который при наведении показывает остаток и список операций дня в стиле glassmorphism, с возможностью редактирования операций через клик.

## Функциональные требования
- FR1: Tooltip появляется ТОЛЬКО при наведении на день с операциями (не на пустые дни)
- FR2: Содержимое tooltip: фактический остаток на день + список операций (до 5)
- FR3: Каждая операция отображает: иконку категории/типа, описание/название, сумму с цветом (+/-)
- FR4: Если операций больше 5, показывается кликабельная кнопка "ещё N..." внутри tooltip
- FR5: При клике на "ещё N..." — раскрывается полный список в том же tooltip (не новое окно)
- FR6: Клик на операцию в tooltip открывает edit-modal через существующий edit-transaction-id Store
- FR7: Клик на виртуальную (recurring) операцию открывает recurring-edit-scope-modal

## Нефункциональные требования
- NFR1: Glassmorphism стиль — полупрозрачный фон с blur эффектом
- NFR2: Хорошо читаемый текст на любом фоне
- NFR3: Плавная анимация появления/скрытия (fade in/out)
- NFR4: Tooltip не перекрывает соседние ячейки при позиционировании
- NFR5: Адаптивность — корректное отображение на мобильных устройствах

## Ограничения
- Использовать существующий паттерн Pattern-Matching callbacks с ADR-003 guard clauses
- Интеграция через существующие Stores: edit-transaction-id, recurring-edit-context
- Не использовать внешние библиотеки tooltip (только Dash + CSS)
- CSS без препроцессоров (plain CSS в app/assets/)

## Критерии приёмки
- [ ] Hover на день с операциями показывает tooltip
- [ ] Hover на пустой день НЕ показывает tooltip
- [ ] Tooltip содержит баланс и список до 5 операций
- [ ] Кнопка "ещё N..." раскрывает остальные операции в том же tooltip
- [ ] Клик на операцию открывает модал редактирования
- [ ] Glassmorphism стиль с blur и полупрозрачностью
- [ ] Плавная анимация появления
- [ ] Unit тесты для новых функций
- [ ] Black + Flake8 без ошибок

## Вне scope (out of scope)
- Drag-and-drop операций между днями
- Создание операций через tooltip (используется существующий клик по дню)
- Изменение поведения клика по дню (остаётся открытие create-modal)
- Tooltip для пустых дней
